# 바이브 코딩 교육

Claude Code 로 실제로 돌아가는 것을 만드는 법을 가르치는 교육자료 레포.

> 상태: **골격만 잡힌 상태.** 커리큘럼 내용은 아직 확정 전이며 차차 채운다.
> 확정되지 않은 항목은 `TBD` 로 표시해 둔다.

---

## 이 레포의 목적

- 교육 세션에서 쓸 자료(슬라이드 대체 문서, 실습 과제, 예제 코드)를 한 곳에 모은다.
- 수강생이 레포를 클론해서 **그 자리에서 실습**할 수 있는 상태를 유지한다.
- 세션이 끝나면 그때 나온 질문·막힌 지점을 자료에 되먹인다.

## 디렉터리 구조

```
vibe-coding-education/
├── README.md          # 이 파일 — 전체 안내, 커리큘럼 목차
├── CLAUDE.md          # Claude Code 작업 지침 (자료 작성 규칙)
├── curriculum/        # 세션별 교육자료 (01-*.md, 02-*.md ...)
├── examples/          # 실습용 예제 프로젝트·코드
└── docs/              # 참고자료, 치트시트, FAQ
```
