# CLAUDE.md — 교육자료 작성 지침

이 레포는 **교육자료 레포**다. 제품 코드가 아니라 사람이 읽고 따라 하는 문서가 산출물이다.

## 문서 규칙

- 언어: 한국어. 기술 용어는 원어 그대로 (예: prompt, context, commit).
- 파일명: `curriculum/NN-주제.md` — 두 자리 번호로 순서를 고정한다.
- 각 자료는 아래 구조를 지킨다:
  1. **무엇을 할 수 있게 되는가** (한 문단, 결과 기준으로 서술)
  2. **왜 이렇게 하는가** (배경·원리)
  3. **따라 하기** (복붙 가능한 명령·프롬프트)
  4. **실습** (수강생이 직접 하는 과제 + 성공 기준)
  5. **흔한 실패** (실제로 겪은 것만. 상상으로 쓰지 않는다)
- 한 자료는 한 세션 분량. 길어지면 번호를 늘려 쪼갠다.

## 예제 코드 규칙

- `examples/` 안의 코드는 **실제로 실행되어야 한다.** 실행 안 되는 코드는 커밋하지 않는다.
- 예제마다 `examples/<이름>/README.md` 에 실행 방법 1줄과 기대 출력을 적는다.
- 의존성은 최소로. 수강생 환경 설치에서 막히는 게 제일 큰 이탈 요인이다.

## 금지 사항

- ❌ 안 해본 것을 해본 것처럼 쓰기. 검증 안 된 절차는 `TBD` 로 남긴다.
- ❌ API 키·토큰·사내 정보를 자료나 예제에 넣기. 항상 `.env.example` + 플레이스홀더.
- ❌ 스크린샷만으로 절차 설명하기. 텍스트 명령을 항상 함께 적는다 (복붙·검색 가능해야 함).
- ❌ 확정 안 된 커리큘럼을 그럴듯하게 채워 넣기. 비어 있는 건 비어 있다고 쓴다.
