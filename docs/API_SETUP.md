# 공공 API 키 발급 가이드

자이씨앤에이 수주레이더가 사용하는 공공 API 4종의 인증키 발급 방법.
**모든 키는 무료**, 발급 후 `.env` 파일에 추가하면 즉시 동작.

---

## 1. 나라장터 (G2B) 입찰공고정보서비스 ★ 최우선

- **알짜성**: ★★★ (=수주 의향 100% 의 발주 직접 정보)
- **발급처**: 공공데이터포털 https://www.data.go.kr
- **API 명**: "조달청 나라장터 입찰공고정보서비스"
- **URL**: https://www.data.go.kr/data/15129394/openapi.do

### 발급 절차 (5분)
1. 위 URL 접속
2. 오른쪽 상단 `회원가입` → 카카오/네이버 간편 가입 가능
3. 페이지 중앙 `활용신청` 버튼 클릭
4. 사용 목적 입력 (예: "자사 수주 영업 정보 분석") → 신청
5. **즉시 자동 승인됨**. 마이페이지 → 인증키 → "일반 인증키 (Encoding)" 복사
6. `.env` 파일에 추가:
   ```
   G2B_API_KEY=발급받은_긴_문자열
   ```

### 사용량
- 일일 1,000 호출 무료
- 우리 시스템은 하루 ~50 호출 사용 (페이지당 100건 × ~50페이지)

### 검증 명령
```bash
python -m src.stage0_collect.nara --days 1 --insecure
```

## 2. DART 전자공시 ★ 두 번째 우선

- **알짜성**: ★★★ (대기업 시설투자 결정 = 가장 빠른 수주 신호)
- **발급처**: https://opendart.fss.or.kr
- **API 명**: OpenDART API

### 발급 절차 (5분)
1. 위 URL 접속
2. 오른쪽 상단 `인증키 신청·관리` 클릭
3. `인증키 신청` → 이메일/이름/소속 입력 → 이메일 인증
4. 인증 완료 후 마이페이지에서 키 확인
5. `.env` 파일에 추가:
   ```
   OPENDART_API_KEY=발급받은_40자_문자열
   ```

### 사용량
- 일일 10,000 호출 무료
- 시설투자 공시는 1일 ~50건 수준 → 부족할 일 없음

### 우리가 가져올 공시 종류
- 단일판매·공급계약체결 (시설공사 수주 측, 참고용)
- **유형자산 취득 결정** (공장 신축·증설 계획 = 알짜)
- 신규시설투자 등의 결정

## 3. 세움터(EAIS) / 건축HUB 건축인허가

- **알짜성**: ★★ (착공 직전, 인허가 단계 = 시공사 선정 중)
- **참고**: 세움터(eais.go.kr)와 건축HUB(cloud.eais.go.kr)는 **같은 시스템의 다른 채널**.
  - 세움터 = 일반 사용자용 웹사이트 (인허가 신청·조회)
  - 건축HUB = 개발자용 데이터 개방 플랫폼 (API)
  - 공공데이터포털은 건축HUB API 중 일부를 재공급

### A안 (권장) — 공공데이터포털 경유, 5분
1. https://www.data.go.kr 접속
2. 상단 검색창에 **`건축인허가`** 검색
3. 검색 결과에서 "국토교통부_건축HUB **건축인허가정보 서비스**" 클릭
4. 우측 `활용신청` 버튼 → 사용 목적 입력 (예: 자사 영업 분석) → **즉시 자동 승인**
5. 마이페이지 → 인증키 → "일반 인증키 (Encoding)" 복사
6. `.env` 파일에 추가:
   ```
   EAIS_API_KEY=발급받은_인증키
   ```

**다른 보조 API**도 같은 방법으로 활용신청 가능 (검색어):
- `건축물대장` — 건축물 기본 정보
- `착공신고` — 착공 직전 단계 정보
- `사용승인` — 준공 정보

### B안 — 건축HUB 직접 가입 (더 풍부, 1-2일 소요)
1. https://cloud.eais.go.kr 접속
2. 회원가입 (사업자 정보 필요 가능)
3. API 신청 → 검토 후 발급
4. 세움터 전체 데이터 접근 (인허가/착공/사용승인/대장 등)

**A안 먼저 시도하고 부족하면 B안 추가** 권장.

## 4. KIND 기업공시 (선택)

- **알짜성**: ★ (DART와 중복이 많아서 우선순위 낮음)
- **발급처**: https://kind.krx.co.kr
- **승인 소요**: 1-2일 (담당자 검토)

대부분 DART로 커버되므로 **DART 잘 작동하면 KIND는 건너뛰어도 됨.**

## .env 파일 위치 및 작성 예시

`.env.example` 을 복사해서 `.env` 로 이름 바꾸고 키 채우면 됨:

```bash
cp .env.example .env
```

```env
# .env (실제 키)
ANTHROPIC_API_KEY=sk-ant-...
G2B_API_KEY=A1B2C3...실제발급키...XYZ%2BTest%3D%3D
OPENDART_API_KEY=40자리실제키
EAIS_API_KEY=A1B2...
```

**주의**: `.env` 는 `.gitignore` 에 들어가 있어서 git 커밋되지 않음.
나라장터 키는 URL 인코딩되어 발급되므로 (`%2B`, `%3D` 같은 문자 포함) **그대로** 붙여넣기.
